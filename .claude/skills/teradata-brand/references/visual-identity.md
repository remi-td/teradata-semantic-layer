# Teradata Visual Identity Reference

## Overview
This document provides comprehensive visual identity guidelines for Teradata brand implementation, including detailed specifications for colors, typography, logos, imagery, and layout systems.

## Color System

### Primary Color Palette

#### Teradata Orange
- **Hex**: `#FF5F02`
- **RGB**: 255, 95, 2
- **CMYK**: C0 M70 Y100 K0
- **Pantone**: 1655 C
- **Usage**: Primary brand color for emphasis, CTAs, key elements, and brand recognition
- **Accessibility**: Passes WCAG AA on white backgrounds for large text (18pt+)

#### Navy
- **Hex**: `#00233C`
- **RGB**: 0, 35, 60
- **CMYK**: C100 M70 Y30 K70
- **Pantone**: 5395 C
- **Usage**: Headlines, body text, structural elements, professional grounding
- **Accessibility**: Passes WCAG AAA on white backgrounds for all text sizes

#### White
- **Hex**: `#FFFFFF`
- **RGB**: 255, 255, 255
- **CMYK**: C0 M0 Y0 K0
- **Usage**: Backgrounds, breathing room, text on dark backgrounds

### Secondary Color Palette
Use sparingly as accent colors to complement the primary palette:

#### Lavender
- **Hex**: `#D8BFD8`
- **RGB**: 216, 191, 216
- **Usage**: Soft accents, background variations, infographics

#### Blue
- **Hex**: `#4A90E2`
- **RGB**: 74, 144, 226
- **Usage**: Data visualization, interactive elements, callouts

#### Green
- **Hex**: `#7ED321`
- **RGB**: 126, 211, 33
- **Usage**: Success states, positive metrics, growth indicators

### Functional Colors
For UI elements and specific communications:

#### Success/Confirmation
- **Primary**: `#7ED321` (Green)
- **Usage**: Confirmation messages, success indicators, positive data

#### Warning/Caution
- **Primary**: `#FFA500` (Orange variation)
- **Usage**: Warnings, alerts, important notices

#### Error/Critical
- **Primary**: `#DC143C` (Crimson)
- **Usage**: Error messages, critical alerts, negative data

#### Information
- **Primary**: `#4A90E2` (Blue)
- **Usage**: Informational messages, tips, neutral callouts

### Color Usage Guidelines

#### Do:
- Lead with Teradata Orange for maximum impact
- Use Navy for structure and professionalism
- Embrace white space generously
- Use secondary colors sparingly as accents
- Maintain color consistency across all materials
- Test color contrast for accessibility (minimum WCAG AA)
- Use functional colors appropriately for their intended purpose

#### Don't:
- Use the wrong orange shade (must be exactly #FF5F02)
- Overuse secondary colors (they should accent, not dominate)
- Create new brand colors or variations
- Use low-contrast color combinations
- Place orange text on navy (insufficient contrast)
- Mix color systems (RGB for digital, CMYK for print - don't mix)

## Typography System

### Font Family: Inter
Inter is Teradata's exclusive brand font. It must be used for all brand communications.

**Why Inter?**
- Modern, clean, and highly legible
- Excellent screen readability
- Professional yet approachable
- Wide range of weights for hierarchy
- Open source and widely available

### Font Weights and Usage

#### Inter Light (300)
- **Use for**: Large headlines, hero text, featured quotes
- **Sizes**: 36pt-72pt typically
- **Character**: Elegant, modern, approachable
- **Avoid**: Body text (too light), small sizes (loses legibility)

#### Inter Regular (400)
- **Use for**: Body text, paragraphs, general content
- **Sizes**: 10pt-14pt typically
- **Character**: Balanced, readable, professional
- **Line spacing**: 1.5x recommended (e.g., 12pt text with 18pt leading)

#### Inter Medium (500)
- **Use for**: Subtle emphasis within body text, subheadings
- **Sizes**: 10pt-16pt typically
- **Character**: Slightly stronger than Regular without being bold

#### Inter SemiBold (600)
- **Use for**: Subheadings, section headers, important callouts
- **Sizes**: 14pt-24pt typically
- **Character**: Strong hierarchy, clear differentiation

#### Inter Bold (700)
- **Use for**: Strong emphasis, button text, important labels
- **Sizes**: Any size as needed
- **Character**: Powerful, attention-grabbing
- **Caution**: Use sparingly - overuse reduces impact

### Typography Hierarchy

#### Recommended Scale (Digital)
- **H1 (Main headline)**: Inter Light, 48pt, Navy
- **H2 (Section header)**: Inter SemiBold, 32pt, Navy
- **H3 (Subsection)**: Inter SemiBold, 24pt, Navy
- **H4 (Minor heading)**: Inter SemiBold, 18pt, Navy
- **Body**: Inter Regular, 16pt, Navy or Black
- **Caption**: Inter Regular, 14pt, Gray (#666666)

#### Recommended Scale (Print)
- **Headline**: Inter Light, 36-48pt, Navy
- **Subhead**: Inter SemiBold, 18-24pt, Navy
- **Body**: Inter Regular, 10-12pt, Navy or Black
- **Caption**: Inter Regular, 8-10pt, Gray

#### Recommended Scale (Presentations)
- **Title slide**: Inter Light, 54-72pt, Navy
- **Section header**: Inter SemiBold, 36-44pt, Navy
- **Slide title**: Inter SemiBold, 28-32pt, Navy
- **Body**: Inter Regular, 18-24pt, Navy
- **Footer**: Inter Regular, 10pt, Gray

### Typography Best Practices

#### Line Spacing
- **Headlines**: 1.1-1.2x (tighter for impact)
- **Body text**: 1.5x (optimal readability)
- **Captions**: 1.3-1.4x

#### Line Length
- **Optimal**: 50-75 characters per line
- **Maximum**: 90 characters per line
- **Short form**: 35-45 characters for callouts

#### Alignment
- **Body text**: Left-aligned (never justified - creates awkward spacing)
- **Headlines**: Left-aligned or centered (based on layout)
- **Captions**: Left-aligned with related content

#### Kerning and Tracking
- **Headlines**: Slight negative tracking acceptable (-10 to -20)
- **Body text**: Default tracking (0)
- **All caps**: Increase tracking (+50 to +100) for readability

### Font Fallbacks
If Inter is unavailable (legacy systems, special circumstances):

**Digital**: System defaults (San Francisco, Segoe UI, Roboto)
**Print**: Helvetica Neue or Arial (note the substitution)

**Important**: Always note when using fallback fonts and return to Inter when possible.

## Logo System

### Primary Logomark: "teradata."

The Teradata logomark consists of the wordmark "teradata" in lowercase with a distinctive dot. The dot is a critical brand element and must never be removed.

#### Logo Variations Available:
1. **Full wordmark** (`teradata_logo_rgb_pos.png`) - Primary use
2. **Symbol/icon** (`teradata_sym_rgb_pos.png`) - Small spaces, social media, favicons

#### Logo Colors:
- **Orange on white/light**: Primary usage (Pantone 1655 C / #FF5F02)
- **White on dark**: For dark backgrounds or photography
- **Navy on light**: Rare alternative when orange is not possible
- **Black on white**: Print only when limited to single color

### Clear Space Requirements

**Minimum clear space**: Height of lowercase "t" on all sides
- This ensures the logo has breathing room
- No text, graphics, or other elements should enter this space
- Maintain clear space even when logo is at minimum size

### Minimum Size Requirements

#### Digital:
- **Full wordmark**: Minimum width 120px
- **Icon**: Minimum 32px × 32px (for clarity)

#### Print:
- **Full wordmark**: Minimum width 1 inch (25.4mm)
- **Icon**: Minimum 0.5 inch (12.7mm) square

### Logo Usage: Do's and Don'ts

#### ✓ Do:
- Use provided logo files only
- Maintain proper clear space
- Place on solid, high-contrast backgrounds
- Use orange logo on white/light backgrounds
- Use white logo on dark backgrounds or photos
- Scale proportionally (maintain aspect ratio)
- Ensure sufficient contrast with background

#### ✗ Don't:
- Stretch, compress, or distort the logo
- Rotate or angle the logo
- Add effects (drop shadows, glows, outlines, gradients)
- Change logo colors (use provided versions)
- Remove or modify the dot
- Place on busy backgrounds without sufficient contrast
- Recreate or redraw the logo
- Place logo too small (under minimum size)
- Use low-resolution versions
- Overlap logo with other elements

### Logo Placement

#### Documents:
- Header: Top left or top center
- Footer: Bottom left or bottom center
- Maintain consistent placement throughout document

#### Presentations:
- Title slide: Prominent placement (top left or center)
- Content slides: Small logo in consistent corner (usually top left or bottom right)
- Closing slide: Larger logo placement

#### Web/Digital:
- Header: Top left (standard web convention)
- Footer: Centered or left-aligned
- Favicon: Use icon version

## Photography Guidelines

### Visual Style
Teradata photography should feel:
- **Contemporary**: Modern, current, relevant
- **Authentic**: Real people, real moments, genuine emotion
- **Human-centered**: People are the focus, not just technology
- **Purposeful**: Clear intent and narrative
- **Diverse**: Representing varied backgrounds, ages, and perspectives

### Subject Matter

#### Primary Subjects:
- Business professionals in authentic work environments
- Collaborative teams solving problems together
- Data at work (screens, dashboards) with human context
- Decision-makers using insights confidently
- Diverse representation across age, gender, ethnicity, ability

#### Secondary Subjects:
- Technology and workspaces (as context, not focus)
- Abstract data visualizations
- Global perspectives (different locations, cultures)

### Treatment and Style

#### Lighting:
- Natural light preferred
- Bright, optimistic, energetic
- Avoid overly dramatic lighting
- Ensure subjects are well-lit and clear

#### Composition:
- Clean, uncluttered backgrounds
- Clear focal point (usually people)
- Thoughtful framing and perspective
- Generous negative space where appropriate

#### Post-Processing:
- Natural color palette
- Slight saturation boost acceptable
- Avoid heavy filters or effects
- Maintain skin tone authenticity

### What to Avoid

#### ✗ Don't use:
- Overly staged or posed photos
- Stock photo clichés (fake handshakes, pointing at screens)
- Dated technology or environments
- Non-diverse casting (all same demographic)
- Low-quality or pixelated images
- Photos that don't relate to data/business context
- Dark, moody, or negative imagery
- Photos with visible competitor brands

### Image Quality Standards

#### Resolution:
- **Print**: Minimum 300 DPI at final size
- **Digital**: 72-150 DPI (based on screen resolution)
- **Web**: Optimized file size while maintaining quality

#### File Formats:
- **Print**: TIFF or high-res PDF
- **Digital**: PNG (with transparency) or JPG (photos)
- **Web**: WebP, PNG, or optimized JPG

#### Sizing:
- Use appropriate image sizes for medium
- Avoid upscaling low-res images
- Crop thoughtfully to maintain composition

## Layout and Grid Systems

### Grid Principles
Teradata layouts use structured grid systems for:
- Consistency across materials
- Clear visual hierarchy
- Balanced composition
- Efficient use of space
- Professional appearance

### Common Grid Structures

#### 12-Column Grid (Digital)
- Standard for web and digital materials
- Flexible for various content types
- Allows for complex layouts
- Responsive breakpoints for mobile

#### 6-Column Grid (Print)
- Standard for brochures and reports
- Clear structure for mixed content
- Good for text-heavy documents

#### 4-Column Grid (Presentations)
- Simple structure for slides
- Easy to achieve balance
- Works well with limited space

### White Space Philosophy

**Principle**: White space (negative space) is not wasted space - it's a critical design element.

**Benefits**:
- Improves readability and comprehension
- Creates visual hierarchy
- Reduces cognitive load
- Communicates professionalism and confidence
- Allows content to breathe

**Guidelines**:
- Embrace generous margins
- Don't feel compelled to fill every inch
- Use white space to separate distinct elements
- Balance text blocks with negative space
- More white space = more premium feel

### Visual Hierarchy

Establish clear hierarchy through:

1. **Size**: Larger = more important
2. **Weight**: Bolder = more important
3. **Color**: Orange for emphasis, navy for structure
4. **Position**: Top-left typically seen first (Western reading patterns)
5. **Proximity**: Related elements grouped close together
6. **Contrast**: High contrast draws attention

### Alignment Guidelines

**Left Alignment (Preferred)**:
- Most readable for body text
- Natural for Western languages
- Professional and clean

**Center Alignment**:
- Headlines and titles
- Short text blocks
- Symmetric layouts
- Call-to-action buttons

**Right Alignment**:
- Rare - use sparingly
- Sometimes for captions or callouts
- Certain layout situations

**Justified Alignment**:
- Avoid - creates awkward spacing
- Exception: Multi-column layouts in print

### Balance and Composition

**Symmetrical Balance**:
- Formal, stable, traditional
- Equal weight on both sides
- Good for corporate materials

**Asymmetrical Balance**:
- Dynamic, modern, engaging
- Unequal but balanced elements
- Creates visual interest

**Radial Balance**:
- Elements radiate from center
- Use sparingly (circular layouts)
- Good for special features

## Expressive Elements

### Graphic Patterns
Teradata uses abstract geometric patterns as background elements:
- **Style**: Angular, data-inspired, abstract
- **Color**: Orange with navy, or reverse
- **Opacity**: 10-30% typically (subtle, not overpowering)
- **Usage**: Background texture, transitions, accent areas

### Data Visualization Style
When creating charts, graphs, and data visualizations:
- **Primary color**: Orange for main data
- **Secondary colors**: Navy, blue, green for additional data series
- **Background**: White or very light gray
- **Grid lines**: Subtle (10-20% gray)
- **Labels**: Navy, Inter Regular
- **Emphasis**: Orange for key data points

## Accessibility Requirements

All Teradata brand materials must meet WCAG 2.1 Level AA standards minimum:

### Color Contrast:
- **Large text (18pt+)**: Minimum 3:1 contrast ratio
- **Normal text**: Minimum 4.5:1 contrast ratio
- **Interactive elements**: Minimum 3:1 contrast ratio

### Typography:
- Minimum 10pt for body text (print)
- Minimum 16px for body text (digital)
- Adequate line spacing (1.5x minimum)
- Avoid italics for long text blocks

### Images:
- Provide alt text for all meaningful images
- Don't rely on color alone to convey information
- Ensure images have sufficient contrast

### Documents:
- Logical heading structure (H1 > H2 > H3)
- Meaningful link text (not "click here")
- Table headers properly marked
- Lists structured semantically
