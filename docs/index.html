Application

Five principles the code refuses to compromise on

Everything else in the product follows from these five decisions.

I

The catalog is the engine

Metadata lives in Teradata tables, not in a YAML repo that has to be deployed. The compiler reads what the database already knows. No separate metrics service to keep in sync, no build pipeline, no snapshot drift.

II

One process, one identity, one audit trail

MCP tools and REST endpoints share the same FastAPI process, the same bearer token, the same connection pool, and the same query log. Agents and humans leave indistinguishable footprints in DBQL — what auditors actually want.

III

Compile in Python, execute in Teradata

The resolver and join planner are ordinary Python behind a CatalogDAO Protocol. InMemoryCatalog runs every resolver test in under a second. Production swaps in a teradatasql-backed DAO. Same code path, no mocks in CI.

IV

Stateless replicas, authoritative database

Each FastAPI process holds at most four pooled connections and zero cross-request state. Horizontal scale is "add a replica." Cache invalidation is not a problem because there is no cache to invalidate.

V

A cube is a dataset

Register a pre-canned query as a single cube on Monday. Decompose it into facts and dimensions on Friday. Both patterns coexist in the same ontology. Progressive maturity, zero migration cost, no semantic rewrite.

Information

Twelve concepts, one semantic vocabulary

The catalog schema is the contract. Every tool — GUI, REST, MCP, exporter — reads and writes the same tables.

Model

A named container: one per domain or subject area. Owns datasets, metrics, relationships, and views.

Dataset

A table, view, or registered cube that contributes to the model.

Field

A column on a dataset. Tagged as K (key) or A (attribute).

Metric

SIMPLE, RATIO, CUMULATIVE, or DERIVED. Carries aggregate fn + arg.

Metric filter

Row-level filter on a base metric. Compiles to AGG(CASE WHEN … THEN arg END).

Relationship

Typed join between datasets with a cardinality and an optional role name.

Semantic view

Curated projection: the certified slice exposed to consumers.

View member

A metric or dimension exposed inside a semantic view.

AI context

Instructions, synonyms, examples attached to any entity.

Format spec

Display hints: currency, decimal places, date format.

Security policy

Row-level filter per group. Injected at compile time.

What happens to a semantic.execute request

  1. Auth — bearer token verified with hmac.compare_digest; body parsed into Pydantic.
  2. Translate — API model converted to the compiler's own dataclass request. No shared types.
  3. Resolve — model, fields, metrics, filters fetched via CatalogDAO; LogicalPlan of tokens built.
  4. Join — BFS over RELATIONSHIP edges, unused datasets pruned, chasm traps refused.
  5. Secure — SECURITY_POLICY rows matching X-Semantic-Groups appended as WHERE_RAW nodes.
  6. Render — sqlglot AST dialected to Teradata; LOCKING ROW FOR ACCESS prepended.
  7. Validate — read-only verb gate; RAW filter values regex-checked before binding.
  8. Execute — pooled cursor runs the statement; rows stream back as JSON.

p99 is dominated by the Teradata round-trip. Python compilation is sub-millisecond on realistic models.

Security posture

Governed by default, not by exception

Auth

Bearer token compared with hmac.compare_digest. Same token guards /api/* and /mcp/*.

Row-level security

SECURITY_POLICY rows selected by operator-signed X-Semantic-Groups header; injected at compile time.

Injection defense

RAW filter values regex-validated. Identifiers rendered through sqlglot, never concatenated.

SQL gating

EXPLAIN and execute routes accept read verbs only. DDL and DML rejected pre-parse.

Secret redaction

DATABASE_URI password stripped from logs and /api/health. No token echoed in responses.

Supply chain

Apache 2.0. Pinned deps. 148 KB wheel. 119 unit tests green on every build.

    "semantic-catalog": {
      "url": "http://localhost:8080/mcp",
      "headers": { "Authorization": "Bearer ${SEMANTIC_API_TOKEN}" }
    }
  }
}
